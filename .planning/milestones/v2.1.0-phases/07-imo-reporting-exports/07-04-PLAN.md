<objective>
Close T-05-47, the Phase-5 standing debt that this phase was required to decide before RPT-03 could
be built: unphased free-typed money currently blends into the gross realized headline, so the number
a steering committee would read overstates phased-backed value.

D-01 splits it. D-02 computes the split once, in the rollup route, so the screen and the pack read
the same object. D-03 derives unphased at read time from the absence of phasing rows, so nothing has
to be migrated and the figure self-corrects the moment an initiative gains phasing.

This plan also adds the one field the pack's staleness rendering needs that the API does not expose
today — a day count behind the existing boolean — while explicitly leaving D-13 alone.

Purpose: RPT-03's avoid-double-counting requirement and RPT-04's stale-versus-current requirement
both rest on this rollup being right before any pack layout reads it.
Output: split rollup fields, an updated tile row, a stale day count, and a both-directions proof.
</objective>
