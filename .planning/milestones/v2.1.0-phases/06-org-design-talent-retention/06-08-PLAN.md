clean-room contract at the markup level, of the critical severity badge through both conversion paths,
and of the demonstration showcase's continued health.

**The standing trap, stated once more because it has fired in every phase that touched a committed
database file.** A SQLite write against a git-committed write-ahead-log-mode database can land only in
the ignored sidecar, leaving the tracked file byte-unchanged and the working tree apparently clean.
Run a truncating checkpoint before closing the connection and diff the tracked file against HEAD.
`git status` alone is not evidence, and this plan's acceptance criteria require the diff.

the flight-risk register, and 06-CONTEXT.md flags that Phase 7's reporting requirement refers to "the
staleness signals and equivalents" — so Phase 7 may find this missing and need to decide whether to add
it then. The summary must restate that flag so it is not rediscovered as a surprise.
