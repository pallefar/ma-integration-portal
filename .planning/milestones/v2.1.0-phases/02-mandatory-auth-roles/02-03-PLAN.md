<objective>
Make the fail-closed default usable at both ends of the demo/real split: (1) the client fetch wrapper must redirect to `/login.html` on any `authRequired:true` 401 — including now-gated GET reads — so an expired or missing session redirects rather than silently blanking the page (RESEARCH Pitfall 3); (2) the demo release launchers must set `DEMO_OPEN=1` so the showcase stays open under the new fail-closed default (D-02). Depends only on the Plan 01 gate contract (`401 {authRequired:true}` + `isOpenMode`), so it runs parallel to Plan 02.

Purpose: Without the client change, once GET reads are gated a mid-session expiry (12h TTL makes this real, not theoretical) leaves pages rendering empty widgets instead of redirecting to login. Without the launcher flag, the demo bundles would unexpectedly start requiring login.
Output: A read-401 redirect handler in transitions.js and the DEMO_OPEN flag in both launchers.
</objective>
