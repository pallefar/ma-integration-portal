- Every command runs from YOUR worktree root — each `<automated>` starts `cd "$(git rev-parse --show-toplevel)"`;
  never `cd` into the main checkout (that would test the main tree, not your changes).
- Commit after each task. If context pressure forces a stop, stop only at a task boundary and report
  `PARTIAL — resume at Task <N>` naming the exact next task; never leave a task half-applied.
- A command expected to run longer than ~5 minutes is started with the Bash tool's `run_in_background`, output
  redirected to a log that ends with an `EXIT=<code>` line (`( cmd ) > log 2>&1; echo "EXIT=$?" >> log`); wait for the
  completion notification (never a foreground sleep loop), then assert on the log. No foreground `<verify>` chain may
  exceed ~8 minutes.
