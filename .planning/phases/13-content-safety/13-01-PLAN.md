  Node the engines field admits (>=22) without require(esm). Transitive packages whose newest in-range release is < 14
  days old on the execution date are pinned through package.json `overrides` (planner check: launder → 1.7.1,
  postcss → ≤ 8.5.28). If the executor finds a published security advisory affecting 2.17.5 that is fixed only in
  ≥ 2.17.6, take that release instead, raise `engines.node` to `>=22.12` and record why — never a release < 14 days old.
- **PD-1a** Vendoring procedure (zero-install repo with cross-platform prebuilds committed): NEVER run `npm install`
  inside the repository — npm would prune the committed non-host platform binaries (`node_modules/@napi-rs/canvas-*`,
  `node_modules/better-sqlite3/prebuilds/*`). Install into a scratch prefix OUTSIDE the repo with `--ignore-scripts`,
  copy only the new package directories into `node_modules/`, then update the lockfile with
  `npm install --package-lock-only --ignore-scripts` (touches package-lock.json only).
- **PD-2** One allowlist table (`lib/htmlPolicy.js`); the client renderer (13-06) is parity-tested against it.
- **PD-3** Idempotency by fixed point: apply the parser up to 3 passes until output equals input of the pass; if it has
  not converged, return the input fully entity-escaped as text (inert, fail-closed) and count it in a test.
- **PD-4** `DROP_WITH_CONTENT_TAGS` (content discarded): script, style, template, noscript, iframe, object, embed, svg,
  math, textarea, title, xmp, noembed, noframes, select, option. Every other non-allowlisted tag is unwrapped (children
  kept as text/allowed markup) — sanitize-html's `disallowedTagsMode: 'discard'` + `nonTextTags`.
- **PD-5** The i18n dictionary is NOT server-tagged (most values are plain text rendered via textContent; tagging would
  entity-mangle them, the D-15 data-integrity rule); its `[data-i18n-html]` display is sanitized at render by
  MASafeHtml (13-09).

## Executor resume protocol
- Every command runs from YOUR worktree root — each `<automated>` starts `cd "$(git rev-parse --show-toplevel)"`; never
  `cd` into the main checkout. The scratch npm prefix lives under the session scratchpad or `os.tmpdir()`, never inside
  the repo.
- Commit after each task. If context pressure forces a stop, stop only at a task boundary and report
  `PARTIAL — resume at Task <N>`; never leave a half-copied node_modules (Task 1 copies and commits in one step).
- Any command expected to exceed ~5 minutes runs with `run_in_background`, output to a log ending in `EXIT=<code>`
  (`( cmd ) > log 2>&1; echo "EXIT=$?" >> log`); wait for the notification, never a foreground sleep loop.
