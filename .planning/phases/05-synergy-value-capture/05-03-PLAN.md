## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → `POST /api/synergies/:id/stage` | An untrusted body proposes a target stage and an optional reason; the gate decision is made entirely server-side |
| Browser → `POST /api/synergies/:id/rebaseline` | A privileged action reachable by any session that already passed the broader `/api/synergies` write policy (admin, hrbp AND pmo) — the narrowing to admin+hrbp happens only inside this handler |
| Browser → `POST /api/synergies` | The generic upsert, an alternative route through which a stage change or an unexplained re-baseline could otherwise be smuggled |
