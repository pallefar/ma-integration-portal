<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Rendered markup → browser DOM | Cost-entry notes, initiative titles and owner names are stored free text reaching an `innerHTML` string concatenation on the execution tab |
| Rollup response → rendered figures | The client displays money figures it does not compute; a client that recomputed them could disagree with the server |
| Deal-home nudge → session storage | A dismissal flag is written to session storage under a key shared with nothing else |

|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-36 | Repudiation | rollup figures recomputed client-side | high | mitigate | Every headline figure and the stale flag are read from the server's rollup response rather than recomputed in the browser; a source-level check confirms the client performs no staleness computation from timestamps, so a wrong client clock cannot make a stale figure read as current |
